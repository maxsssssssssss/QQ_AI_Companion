## 新规则

| 项目 | 候选值 |
|---|---|
| 模式 | `continuous`，无72小时截止，不设置结束日期 |
| 允许时段 | `Asia/Shanghai`，每日09:00:00–23:59:59（+08:00） |
| 主动发送尝试 | 每天最多5次，失败和unknown也消耗次数 |
| 尝试间隔 | 至少10800秒（3小时），跨午夜不重置间隔 |
| 主模型评估 | 每天最多5次；send、skip、defer、空正文、失败均消耗一次评估 |
| 目标与内容 | 现有唯一授权私聊，普通文本；同一计划可含多个气泡 |

评估和发送分别计数。skip/defer只消耗评估额度，没有发送时不伪造发送尝试；一次计划即使有多个气泡也只算一次主动尝试，每个气泡仍独立记录结果。额度在北京时间日期变化时更新，账本持久化，重启和失败不返还额度。上限不是每天必须完成的数量。后台搜索、其他联系人与群聊不因此开放，被动对话不受这些主动额度限制。
